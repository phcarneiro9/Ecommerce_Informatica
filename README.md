## 📌 Sobre o Projeto

API REST de um sistema de **E-commerce de Informática** desenvolvida com **Java e Spring Boot**.

O projeto realiza o gerenciamento de clientes e pedidos com CRUD completo, relacionamento entre entidades e pesquisa personalizada.

---

## 🚀 Tecnologias

☕ Java 17  
🌱 Spring Boot  
💾 MySQL

📡 API REST  
🚀 Insomnia  
🐙 Git e GitHub

## 🔧 Funcionalidades

👤 **Clientes**
- Cadastro
- Consulta
- Atualização
- Exclusão

📦 **Pedidos**
- Cadastro
- Consulta
- Atualização
- Exclusão

🔎 **Pesquisa personalizada**

```http
GET /pedidos/pesquisa?cliente=Patrick
```

---

## 💾 Banco de Dados

**MySQL**

Tabelas:

- `tb_clientes`
- `tb_pedidos`

Relacionamento:

```text
Cliente 1 -------- N Pedido
```
